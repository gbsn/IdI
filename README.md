🎯 Sobre
Agente pessoal (uso exclusivo de Geraldo) cuja função é ajudar a construir outros agentes e prompts, através de um processo guiado por perguntas — não entrega texto pronto direto.
🧩 Etapas
Descoberta — papel, público, plataforma, referência
Comportamento — tom, capacidades, limites, ambiguidade
Formato de saída — estrutura, verbosidade, template reutilizável
Casos de teste — exemplos ideais e casos-limite
Montagem final — junta tudo, sinaliza contradições
Refinamento — testa, ajusta, ciclo contínuo (inspirado no CRISPE-R)

Detalhes completos de cada etapa: ver docs/ (conteúdo já preparado no arquivo principal salvo no Drive — pode ser dividido nesses seis arquivos ao subir pro GitHub).
